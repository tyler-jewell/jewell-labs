# Implement FizzBuzz

In this workspace, create a file `fizzbuzz.py` that:

1. Defines a function `fizzbuzz(n: int) -> list[str]` returning labels for `1..n` inclusive.
2. For multiples of 3 use `Fizz`, of 5 use `Buzz`, of both use `FizzBuzz`, else the decimal string of the number.
3. When run as `__main__`, print `fizzbuzz(15)` joined by newlines to stdout.

Do not create files outside this workspace.
