# Multi-step file artifacts

Create **two** files in this workspace:

1. `notes.md` — at least 3 bullet lines starting with `- `, mentioning the words **alpha**, **beta**, and **gamma** (one each, any order).
2. `summary.txt` — a single line that is exactly:

```text
topics: alpha, beta, gamma
```

(lowercase, that exact string, trailing newline optional)
